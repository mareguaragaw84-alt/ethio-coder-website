MAREGU IT & WEB DEVELOPMENT WEBSITE
====================================

Files
- index.html : page structure and content
- style.css  : responsive design and styling
- script.js  : mobile navigation, active menu state, and current year

How to run
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js in the same folder.
3. Double-click index.html to open it in a modern browser.
4. To publish online, upload the three files to your hosting provider.
